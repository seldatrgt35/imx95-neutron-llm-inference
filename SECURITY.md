# Repository security

This repository contains only source files, textual observations, and rendered diagrams. It does not distribute models, firmware, driver libraries, or BSP images. Before publishing new terminal captures, inspect for access tokens, internal network addresses, hostnames, credential files, and personally identifying information. Use an allow-list of approved evidence if unsure.

Device-tree, U-Boot, CMA, and firmware updates can make a board unbootable. The commands in the documentation are observational unless they are explicitly flagged as a controlled experiment with backup and rollback instructions.
