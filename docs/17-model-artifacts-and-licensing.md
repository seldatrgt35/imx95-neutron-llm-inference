# Model artifacts and licensing

No downloaded Qwen3-4B weights, large `model.onnx.data` tensor file, tokenizer repository snapshot, external datasets or vendor-bundled model/firmware binaries are redistributed. Historical file paths are contextual, not download links. Anyone reproducing the work must obtain model and BSP artifacts from their original publishers under the corresponding terms.

The `*.onnx` and `*.safetensors` exclusions in `.gitignore` intentionally prevent accidental publishing of multi-gigabyte weight files. The project retains `.py`, `.md`, `.svg`, `.png`, `.json` and verified textual console evidence. The owners of third-party source code and models retain their respective intellectual property rights.

The repository does not currently include a blanket license, because one should not implicitly sublicense third-party snippets. The owner can separately license truly original project code and documentation after verifying their provenance.
